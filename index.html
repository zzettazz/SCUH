Conectar mi cuenta

Una web no puede leer tu cuenta de RSI por su cuenta (el navegador lo impide por seguridad). Para eso está el marcador: lo pulsas estando en RSI y lee tus datos con tu propia sesión.

  1. Arrastra este botón a tu barra de marcadores (si no la ves: Ctrl+Shift+B, o ⌘+Shift+B en Mac):
    🚀 RSI Helper

    Si no puedes arrastrarlo: crea un marcador nuevo y pega como URL el código de abajo.

    Ver el código del marcador
  2. Abre robertsspaceindustries.com e inicia sesión.
  3. Pulsa el marcador 🚀 RSI Helper. Aparecerá un panel en la web de RSI.
  4. Pulsa «Leer mi cuenta y abrir la web». Tarda unos 25 segundos (o 55 si incluyes el historial) y esta web se abrirá con tus datos.

Privacidad y seguridad

  • No hay servidor: tus datos se guardan solo en este navegador.
  • El marcador solo lee: no compra, aplica, canjea ni regala nada. Nunca ve tu contraseña.
  • Al compartir tu flota, el enlace solo lleva nombre, rol, tamaño, tripulación y carga de cada nave.
